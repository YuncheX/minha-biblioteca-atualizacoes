# Atualizações da Minha Biblioteca

Arquivos públicos do programa. Não envie bibliotecas, backups pessoais, tokens ou a chave privada de publicação.

Para publicar: envie o HTML numerado e atualizacao.json juntos para a raiz da branch main. O aplicativo consulta atualizacao.json e valida a assinatura antes de aceitar o HTML. As próximas versões precisam ser assinadas pela mesma chave privada guardada localmente no projeto.

O HTML pode ser baixado e usado separadamente. Os dados são guardados no navegador ou no aplicativo do usuário. Esta publicação não recebe os dados da biblioteca.

O mecanismo atual atualiza somente o HTML. O executável Windows exige atualização do pacote completo e não tem assinatura de fornecedor reconhecido pelo Windows. A assinatura das atualizações de HTML não substitui essa assinatura do executável.
